JabberCafe 0.12.0-rev.000022 — Windows x64

1. Extract the ENTIRE ZIP into a new folder.
2. Keep JabberCafe.pck next to the executable.
3. Run JabberCafe.exe.
No Godot editor is required to play.

CUSTOMIZE
The music widget starts as a slim bottom-right card. Press its ⋯ button, or
Settings → Interface → Customize panels. Select a panel and adjust layout,
width, height, control/text scale and dock/free position independently.
Close/minimize leaves a Music button and does not stop playback.
Settings → Display → Interface & adaptive graphics controls display density,
native fullscreen and Auto/Quality/Balanced/Performance/Custom 3D rendering.

MUSIC
Right-click the DJ booth → My Tracks. Saved mixes and Ready for booth remain
separate. Prepare a mix, select it for the line, then join the DJ line.
Set the creator credit for new prepared tracks in Interface settings.
Existing finished versions retain their prior title/audio/artist.

UPDATING
Back up the complete existing user-data folder before updating. Its application
identity is unchanged. Do not move just the executable or mix old/new PCK files.
The game remains offline. See the included guides and VALIDATION.txt.
